## 🚀 About

Weblog-2 is a full-featured blogging platform built using Django. It offers a smooth and secure user experience with modern UI and essential blog functionality. The project emphasizes clean architecture, security best practices, and maintainability.  [oai_citation:1‡GitHub](https://github.com/ho3inmonfared/weblog-2)

---

## ✨ Features

✔️ User authentication (signup/login/logout)  
✔️ Create, edit, and delete blog posts  
✔️ Author profiles and user management  
✔️ Likes & comments on posts  
✔️ View count and statistics  
✔️ Responsive UI for desktop and mobile screens  
✔️ Deployed live on Render (fast and reliable)  [oai_citation:2‡GitHub](https://github.com/ho3inmonfared/weblog-2)
